# 🛒 Smart Basket – Food Expiry Tracker

## 📌 Overview

Smart Basket is a web application that helps users track food items and their expiry dates to reduce food wastage.

---

## 🚀 Features

* 📅 Track food expiry dates
* 🔔 Alerts for expiring items
* 🛍️ Smart inventory management
* 📊 Dashboard for overview
